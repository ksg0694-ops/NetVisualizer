# 월급 배분 실제 거래와 규칙 비교

## 결론

청년도약계좌, 연금저축펀드, 신용대출 이자, 전세대출은 현재 규칙과 실제 거래가 일치한다. 가장 큰 차이는 생활비와 원화 발행어음이다.

현재 모델은 월급에서 생활비 100만원을 매달 새로 떼어 놓는다고 계산한다. 실제 행동은 기존 잔액을 포함해 월급통장과 생활비통장의 합계 잔액을 100만원으로 맞추고, 남은 돈을 원화 발행어음으로 보내는 방식이다. 따라서 생활비는 월 배분액이 아니라 목표 잔액으로 다뤄야 한다.

## 비교 기준

- 기준 기간: 2026년 6월 급여기간, 2026-05-22 ~ 2026-06-24
- 월급: 3,776,000원
- 비교 대상: 월급일 직후의 배분 거래
- 실제 거래 출처: 앱의 현금 흐름 상세 내역
- 규칙 출처: `cashFlowAdapter.ts`의 월급 배분 계산

## 2026년 6월 비교

| 항목 | 현재 그래프 | 실제 거래 기반 | 차이 | 판단 |
| --- | ---: | ---: | ---: | --- |
| 청년도약계좌 | 700,000원 | 700,000원 | 0원 | 일치 |
| 연금저축펀드 | 100,000원 | 100,000원 | 0원 | 짝 없는 10만원 이체로 추정 |
| 신용대출 이자 | 269,457원 | 269,457원 | 0원 | 일치 |
| 전세대출 | 1,000,000원 | 1,000,000원 | 0원 | 일치 |
| 생활비 | 1,000,000원 | 588,041원 | -411,959원 | 기존 통장 잔액을 반영해야 함 |
| 원화 발행어음 | 706,543원 | 1,118,502원 | +411,959원 | 상대 계좌 정보가 없어 중간 신뢰도 추정 |

목적지 합계는 두 방식 모두 월급 3,776,000원과 일치한다. 차이는 생활비 목표 잔액 중 기존 잔액 411,959원을 월급에서 다시 배분한 것으로 계산했기 때문에 발생한다.

### 실제 흐름 재구성

- 생활비통장 순유입: 100,000원 + 500,000원 - 282,307원 = 317,693원
- 급여통장 잔존액 추정: 270,348원
- 이번 월급이 생활비 목표 잔액에 기여한 금액: 317,693원 + 270,348원 = 588,041원
- 기존 두 통장 잔액 기여분: 1,000,000원 - 588,041원 = 411,959원
- 원화 발행어음 추정: 2,000,000원 - 1,000,000원 + 118,502원 = 1,118,502원

원화 발행어음 금액은 해당 이체의 상대 계좌가 거래 행에 직접 표시되지 않아 사용자가 설명한 배분 행동과 금액 보존식으로 추정했다.

## 2026년 7월 진행 중 신호

2026년 7월 급여기간은 2026-06-25 ~ 2026-07-23이며 아직 진행 중이다. 현재 데이터는 2026-06-25 거래까지만 있어 완전한 월 비교에는 사용할 수 없다.

| 항목 | 관측값 | 해석 |
| --- | ---: | --- |
| 월급 | 3,998,000원 | 전월보다 222,000원 증가 |
| 청년도약계좌 | 700,000원 | 규칙과 일치 |
| 연금저축펀드 | 100,000원 | 짝 없는 10만원 이체로 추정 |
| 신용대출 이자 | 273,267원 | 전월보다 3,810원 증가 |
| 전세대출 | 1,000,000원 | 규칙과 일치 |
| 생활비통장 순이체 | 99,778원 | 400,000원 유입 후 300,222원 반환 |
| 원화 발행어음 | 확인 불가 | 관련 이체 또는 최신 데이터가 없음 |

생활비통장은 카드대금 199,778원이 빠진 뒤 월급통장에서 400,000원을 받고 300,222원을 반환했다. 결과적으로 기존 600,000원에서 목표 500,000원으로 맞춘 흐름으로 해석할 수 있어, 생활비가 고정 월 배분액이 아니라 잔액 목표라는 결론을 다시 지지한다.

## 데이터 품질 판단

- 높은 신뢰도: 월급, 청년도약계좌, 신용대출 이자, 전세대출
- 중간 신뢰도: 연금저축펀드. 동일 시점의 짝 없는 10만원 이체로 식별한다.
- 중간 신뢰도: 원화 발행어음. 상대 계좌 또는 자산 계정 연결 정보가 필요하다.
- 낮은 완결성: 2026년 7월. 데이터가 2026-06-25 이후 갱신되지 않았다.

## 다음 구현 계획

### 1. 급여기간 정산 원장

월급일 주변의 내부 이체를 금액과 시각으로 짝지어 한 흐름으로 묶는다. 대출통장과 생활비통장처럼 중간 계좌를 거치는 이체는 순액만 목적지 배분으로 계산한다.

완료 조건:

- 청년도약계좌의 출금과 입금을 한 건으로 계산한다.
- 대출통장 선입금, 이자 납부, 잔액 반환을 신용대출 이자 한 건으로 계산한다.
- 생활비통장 유입과 반환을 순액으로 계산한다.
- 관측, 추정, 미확인 상태를 항목별로 기록한다.

### 2. 생활비를 목표 잔액으로 변경

현재의 `월급통장 50만원 + 생활비통장 50만원 = 월 배분 100만원` 계산을 제거한다. 각 통장의 급여 직전 잔액과 목표 잔액의 차이만 이번 월급의 생활비 배분액으로 계산한다.

필요 데이터:

- 급여 직전 또는 이체 직전의 계좌 잔액
- 이체 이후의 계좌 잔액 또는 거래별 잔액
- 데이터가 없을 때 사용할 사용자 확인값

잔액 데이터가 없으면 목표 100만원과 실제 순이체를 별도로 보여주고 임의로 같은 값으로 만들지 않는다.

### 3. 실제와 규칙 비교 UI

Personal CFO에 `마감월`과 `진행 중` 전환을 추가하고 각 목적지에 다음 상태를 표시한다.

- 실제: 거래에서 직접 확인
- 추정: 거래 짝과 잔액 보존식으로 계산
- 미확인: 데이터가 부족함
- 목표: 사용자가 설정한 규칙

그래프에서는 실제 금액을 기본으로 사용하고, 목표 금액은 보조 라벨로 표시한다. 원화 발행어음처럼 확인되지 않은 금액을 실제값처럼 단정하지 않는다.

### 4. 사용자 규칙 설정

실제 비교 화면이 안정된 뒤 월급통장 목표, 생활비통장 목표, 연금 이체액, 청년도약계좌, 원화 발행어음 계좌 식별 규칙을 사용자 override로 옮긴다.

## 권장 순서

3. 실제·추정·목표 비교 화면
4. 사용자 override 설정
5. 3개 급여기간이 쌓인 뒤 다음 달 배분 예측
