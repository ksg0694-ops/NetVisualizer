# Update 1.04.02 Design

## 정보 구조

- 생활 도구: `할 일`, `학습 아카이브`
- Todo 그룹: 고정된 `Career / Finance / Life`가 그룹이므로 사용자 입력 그룹은 두지 않는다.
- Life 그룹: Pocket Notebook과 Life 할 일 목록을 같은 `할 일` 탭에 연속 배치한다.
- Todo 상태: `is_done`과 `is_paused`를 독립 값으로 유지한다.
- Step: 기존 JSON 배열에 `groupName`, `detail`을 추가한다.
- 완료 보고서: 요약/성과/Monitor 내용을 `completion_report`에, 업로드 메타데이터를 `report_files`에 저장한다.

## Life 그룹의 생활 노트

선택된 5안인 Pocket Notebook을 기준으로 구현한다.

- PC: 왼쪽 Quick Capture·카드 목록 + 오른쪽 넓은 상세 편집기
- 모바일: 메모/체크/보류 탭 + Quick Capture + 2열 카드
- 보류 카드: 낮은 채도와 높은 투명도로 Monitor 상태를 표현한다.
- 내비게이션: 별도 `생활 노트` 메뉴를 만들지 않고 `할 일 > Life`에서 접근한다.

## 학습 아카이브

- 왼쪽: 분야/항목/Chapter 트리 및 검색
- 오른쪽: 상세 학습 노트 편집기
- 노트 속성: 태그, 참고 링크, 고정 상태

## 서버 계약

- 신규 테이블은 현재 단일 사용자 public-server 정책과 같은 소유자 규칙을 사용한다.
- 완료 보고서 Storage는 로그인 사용자별 private 경로를 사용한다.
- 신규 Todo 컬럼 배포 전에도 기존 스키마로 재시도해 로컬 기능을 보존한다.

## Todo Workbench 최종 구조

- 좌측: Career/Finance/Life를 고정 순서로 동시에 표시하며, 영역 헤더 아래 카드에는 제목과 필요한 상태만 남긴다.
- 중앙: 제목, 상태 select, 영역 select, Monitor 버튼, 닫기 버튼과 전체 폭 상세내역 편집기를 배치한다.
- 우측: 완료된 할 일의 보고서 목록, 검색/정렬, 선택 보고서 미리보기, PPT 생성/업로드를 항상 표시한다.
- 1280px 이상은 3열, 그 미만은 단일 열로 쌓고 모바일 상세 편집기는 전체 화면으로 연다.
- 상세 저장 시 화면에서 제거한 Step 편집 DOM이 없으면 기존 Step 배열을 변경하지 않는다.

## 완료보고서 링크 입력

- 우측 라이브러리 헤더에 `PPT 링크 추가` 버튼을 두고 선택 보고서의 링크 입력으로 이동한다.
- 외부 링크 입력, 명시적 저장 버튼, 저장된 링크 열기를 한 카드 안에 배치한다.
- `http/https` 주소만 허용하고 스킴이 없으면 `https://`를 보완한다.
- 링크 저장 시 기존 결과 요약, 핵심 성과, Monitor, 업로드 파일 메타데이터를 덮어쓰지 않는다.

## 할 일별 Report Library 정정 설계

- 우측 패널은 완료된 할 일의 전역 목록이 아니라 현재 선택한 할 일 한 건의 Library를 표시한다.
- 링크 항목은 `report_files` JSON 배열에 `kind`, `name`, `url`, `createdAt`으로 추가해 한 할 일에 여러 건을 저장한다.
- 기존 업로드 파일도 같은 배열에서 파일 항목으로 표시한다.
- `Report 제목 + PPT 링크` 입력, 링크 열기, 링크 삭제, 파일 업로드를 제공한다.
- 모바일에서 상세 편집기를 닫으면 선택은 유지하고 해당 할 일의 Library로 이동한다.
- 과거 `completion_report.externalUrl` 값은 `이전 PPT 링크`로 읽어 데이터 손실 없이 호환한다.

## OneNote 편집 도구 설계

- 상세내역 원문은 서버와 호환되는 일반 문자열로 유지한다.
- 들여쓰기는 선택한 줄마다 공백 3개를 앞에 추가한다.
- 체크박스는 `- [ ]`, 완료 상태는 `- [x]`로 저장하며 미리보기에서 직접 전환한다.
- 아이콘은 `{{icon:key}}` 토큰으로 저장하고 허용된 Font Awesome 아이콘만 렌더링한다.
- 링크 유형은 제목·URL·경로의 Slides/PPT 및 Sheets/Excel 패턴으로 판별하며, 알 수 없으면 일반 링크로 표시한다.
- 기존 업로드 파일 메타데이터는 계속 열 수 있지만 신규 업로드 컨트롤은 노출하지 않는다.

## 수정패치 설계

- `keydown`에서 상세내역 편집기의 Tab 기본 포커스 이동을 막고 공백 3개를 삽입한다.
- Shift+Tab은 각 대상 줄의 선행 공백을 1~3개 제거한다.
- 선택 영역이 있으면 모든 대상 줄을 함께 처리하고 선택 상태를 유지한다.
- 미리보기는 도구 모음과 textarea 사이에 배치해 스크롤 없이 즉시 확인한다.
- 체크박스는 12×12 CSS px, `inline-flex/items-center`로 텍스트와 수직 중앙 정렬한다.
- 생활노트 스크립트·렌더 컨테이너·PWA 캐시 참조를 제거하고 저장소 데이터 삭제는 수행하지 않는다.
