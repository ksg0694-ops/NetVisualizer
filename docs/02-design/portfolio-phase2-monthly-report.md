# 포트폴리오 월별 Report Phase 2

## 목적

현재 원화 입력 중심의 포트폴리오를 보유수량·시장가격·환율 기반 평가 구조로 전환하고, 월별 Report에서 Port별 변화와 수익률을 추적한다.

## Phase 2 화면

1. 자산을 운영자산·안전자산·투자자산·주거자산·연금으로 구분한다.
2. 투자자산은 사용자가 정의한 Port별 월간 평가액 추이를 표시한다.
3. Port 선택 시 보유항목, 수량, 현재가, 적용 환율, 평가액, 수익률과 최근 추이를 표시한다.
4. 연금자산은 투자 Port와 분리한 장기 추이를 제공한다.
5. 월별 Report의 포트폴리오 영역은 위 화면의 요약본으로 제공한다.

## 필요한 데이터

| 데이터 | 용도 |
| --- | --- |
| 계좌·종목의 보유수량 | 평가액 계산의 기준 |
| 종목 통화와 가격 출처 | 원화 환산 및 데이터 출처 표시 |
| 가격 기준일과 현재가 | 월말 평가액 계산 |
| 환율 기준일과 적용 환율 | 외화자산 원화 환산 |
| Port 식별자 | Port별 집계와 클릭 상세 |
| 월말 보유 스냅샷 | 과거 추이 재현 |
| 평균매입단가 | 수익률 계산 |

평가액은 `보유수량 × 현재가 × 적용 환율`로 계산한다. 사용자가 입력한 원화 금액은 시장 데이터 누락 시 보정값으로만 사용한다.

## 이행 원칙

- 기존 포트폴리오 화면과 현재 자산 합계는 Phase 2 전까지 유지한다.
- 6월·7월 자산 총액은 별도 승인 없이 소급 수정하지 않는다.
- 7월 마감값을 기준점으로 삼고 8월부터 월말 스냅샷을 축적한다.
- 같은 화면에서 자산 목적과 상품 유형을 혼합하지 않는다.
- 가격 또는 환율이 없는 자산은 추정하지 않고 미확정 상태를 표시한다.

## CFO 목적 분류

| 그룹 | 포함 기준 | 현재 평가액 |
| --- | --- | ---: |
| 운영자산 | 생활비통장과 월급통장 | 1,000,000원 |
| 안전자산 | 청년도약계좌, 발행어음, IMA 등 원금 방어 목적 상품 | 102,876,176원 |
| 투자자산 | 주식, ETF, 펀드와 투자계좌 내 대기자금 | 42,402,727원 |
| 주거자산 | 전세금, 주택청약 자금과 주거 관련 대출 | 자산 150,000,000원 / 상환 65,000,000원 |
| 연금 | 연금계좌 내 보유상품 | 4,349,953원 |

- 계좌 폴더명보다 상품 속성을 우선한다. 예를 들어 투자계좌에 들어 있는 `한국투자 IMA S1`은 안전자산으로 분류한다.
- 잔액이 없는 중간 이체용 `대출통장`은 포트폴리오 목록에서 제외한다.
- 주거 관련 대출은 주거자산에 배치하고 자산과 상계해 숨기지 않고 `상환` 금액으로 별도 표시한다.
- 자산군 순서는 고정하고, 각 자산군 내부 항목과 투자계좌는 금액 절댓값 기준 내림차순으로 정렬한다.
- 운영자산은 예외적으로 `생활비통장`, `월급통장` 순서를 유지한다.
- 위 다섯 그룹의 총자산은 300,628,856원, 총부채는 65,000,000원, 순자산은 235,628,856원이다.

## 완료 조건

- Port별 평가액 합계와 투자자산 합계가 일치한다.
- 운영·안전·투자·주거·연금 합계와 총자산 분류가 일치한다.
- 외화자산의 가격일·환율일·원화 평가액을 확인할 수 있다.
- Port 클릭 상세와 월별 Report 요약이 동일한 스냅샷을 사용한다.
- 데스크톱과 모바일에서 Port 선택과 상세 확인이 가능하다.

## 2026-07-28 구현 상태

- 평가식은 `수량 × 현재가 × 원화환율`로 통합했다.
- 현재가·환율이 없는 항목은 기존 입력 원화금액으로 유지하고 평가 출처를 표시한다.
- 투자자산 23개 항목은 지수추종·성장/개별주·현금대기 Port로 집계한다.
- Monthly Report에는 같은 평가 모델을 사용하는 Port별 원화 평가 요약을 연결했다.
- 투자 상세에는 현재가 통화 선택, 환율 기준, 원화 평가액, 원가와 손익 상태를 표시한다.
- `portfolio_fx_rates`와 `portfolio_monthly_snapshots`를 원격 DB에 추가했다.
- 2026-08 시작 기준점은 투자자산 42,402,727원으로 저장했다.
- 아직 18개 ticker의 현재가와 평균매입단가가 비어 있어 수익률은 확정하지 않는다.
- 6월·7월 자산 이력은 수정하지 않았다.
