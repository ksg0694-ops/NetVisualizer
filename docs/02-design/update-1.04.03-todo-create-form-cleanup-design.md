# Update 1.04.03 Todo 신규등록 정리 설계

## 화면 동작

- `할 일 추가`를 누르면 열려 있던 상세 패널을 닫고 신규등록 모달에 제목 포커스를 준다.
- 신규등록 모달을 상세 패널보다 높은 레이어에 배치한다.
- 신규등록 폼에서 Step/Subgroup 편집기를 렌더링하지 않고 신규 데이터는 빈 Step 배열로 저장한다.

## 문구 정리

- 정적 Daily Loop 예시와 반복되는 빈 상태 설명을 제거한다.
- 상세 헤더의 편집 방법 안내를 제거한다.
- 기존 Step이 있는 항목에만 Step 개수를 표시한다.

## 호환성

- 과거 할 일에 저장된 Step 데이터와 기존 상세 편집 기능은 유지한다.
- Service Worker 캐시를 `v177`로 올리고 Todo 스크립트 버전을 갱신한다.
