# Update 1.04.03 Todo 선택·상태 필터 설계

## 텍스트 선택

- pointer와 mouse 드래그 이동을 모두 추적한다.
- 두 줄 이상에 걸친 실제 선택 Range를 짧게 복제해 마지막 click 이벤트에도 유지한다.
- 내용이 있는 편집기 바닥을 클릭했을 때 커서를 강제로 마지막 줄로 옮기지 않는다.
- 편집기에는 native text selection 스타일을 명시한다.

## 목록 필터

- 상세 헤더의 상태 필터를 제거한다.
- 왼쪽 목록의 정렬 select 자리에 상태 필터를 배치한다.
- 정렬 상태와 최근 수정 정렬 분기를 제거하고 저장된 기본 순서를 유지한다.
