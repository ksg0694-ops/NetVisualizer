# Update 1.04.01 데이터·상호작용 설계

## 1. 사용자 정의 전략

전략 이름과 순서는 `portfolio_strategy_definitions`에 저장한다.

| 필드 | 역할 |
|---|---|
| `strategy_tag` | 종목과 연결되는 변경하지 않는 저장 키 |
| `label` | 사용자가 변경할 수 있는 화면 이름 |
| `color` | 전략 박스 식별 색상 |
| `icon` | Font Awesome 아이콘 |
| `display_order` | 전략 박스 순서 |
| `is_active` | 화면 표시 여부 |

이름 변경은 `label`만 수정하므로 해당 전략에 속한 모든 종목이 그대로 유지된다. 새 전략은 `custom_...` 키를 발급하고 빈 전략 박스로 추가한다.

`portfolios.strategy_tag`의 고정 여섯 값 제약은 제거한다. 기존 데이터는 변경하지 않고 새 정의 테이블의 여섯 기본 전략과 연결한다.

## 2. 전략별 수익률

각 전략에서 평균매입단가와 현재가가 모두 있는 종목만 합산한다.

```text
전략 수익률 = 전략 내 미실현손익 합계 / 전략 내 매입원가 합계 × 100
```

비교 가능한 종목이 없으면 `수익률 계산 대기`로 표시한다. 일부 종목만 계산 가능한 경우 계산된 종목 수를 함께 표시한다.

## 3. 달력연도 Roadmap

기준월 다음 달부터 2028년 12월까지 월별 예상 자산을 계산하고, 2026·2027·2028년의 마지막 월을 체크포인트로 사용한다.

- 2026: 기준월 다음 달부터 12월까지
- 2027: 1월부터 12월까지
- 2028: 1월부터 12월까지

연도별 목표는 `short_term_roadmap_goals`에 저장한다. 화면은 예상 자산, 사용자 목표, 예상 달성률, 목표 대비 차액을 표시한다.

## 4. 할 일 영역 선택

영역 값은 기존 `career / finance / life`를 유지한다. 화면만 세 개의 상호 배타적인 버튼으로 바꾸고 선택된 값은 숨은 입력에 저장한다. 필터의 `전체` 선택은 영역 입력과 목적이 다르므로 기존 선택 메뉴를 유지한다.

## 5. 할 일 완료

목록 카드에서 네이티브 체크박스를 제거하고 작은 원형 버튼을 사용한다.

- 열림: 흰 배경과 회색 원형 테두리
- 완료: 인디고 배경과 흰 체크
- 클릭 시 기존 `toggleTask` 저장 함수를 그대로 호출

완료 상태의 제목 취소선과 흐림 처리는 유지한다.
