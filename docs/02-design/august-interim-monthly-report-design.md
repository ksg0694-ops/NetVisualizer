# 8월 중간현황 Monthly Report 설계

## 보고서 구조

1. Monthly Report 제목
2. Executive Summary: 선택 월 중간현황 3문장
3. 상태 지표: 기간 진행, 거래 건수, 월말 소비 추정, 저축+잔여율
4. 현금흐름 시각화: 기존 배분 막대와 수입·소비 도넛
5. 장기 목표와 포트폴리오 증거 화면

## 계산 정의

- 보고 기준일: `min(오늘, 선택 기간 종료일)`
- 데이터 최신일: 선택 기간 거래 중 가장 늦은 날짜
- 데이터 경과일: 기간 시작일부터 데이터 최신일까지의 일수(양끝 포함)
- 기간 진행률: 보고 기준일까지의 경과일 / 전체 기간 일수
- 소비: 전체 지출 - 전세대출 상환 - 신용대출 상환
- 현재 일평균 소비: 소비 / 데이터 경과일
- 직전 일평균 소비: 직전 기간 소비 / 직전 기간 데이터 경과일
- 월말 소비 추정: 현재 일평균 소비 × 전체 기간 일수
- 저축+잔여율: `(저축 + 잔여) / 수입`; 수입이 0이면 미표시
- 최대 소비 분야: `지출` 중 `상환`을 제외하고 category별 절대금액 합계가 가장 큰 분야

## 시각 계약

- 새 요약 영역은 차트를 추가하지 않는다. 수치 해석은 compact KPI와 3개 요약문으로 제공하고, 바로 아래 기존 막대·도넛 차트를 근거 시각화로 사용한다.
- 소비 속도 증감은 빨강·초록에 의존하지 않고 `높음/낮음/유사` 텍스트와 부호 있는 비율을 함께 표시한다.
- 기간 진행은 단일 indigo 진행선으로 표시한다.
- 장식 색상은 indigo와 neutral 중심으로 제한한다.

## 예외 처리

- 거래가 없으면 데이터 최신일과 계산 지표를 `-`로 표시한다.
- 수입이 없으면 저축+잔여율 대신 `수입 반영 전`을 표시한다.
- 직전 기간이 없으면 비교 대신 `비교 기간 없음`을 표시한다.
- 데이터 최신일이 오늘보다 과거이면 `데이터 기준` 문구를 항상 노출한다.
