# Update 1.04.01 수정패치 v1 설계

## 자산 추세 기간

`AssetTrendFeature.buildFullSeries()`가 다음 범위를 생성한다.

- 시작: 보유한 자산 이력의 최초 데이터
- 실제 데이터: 기존 월별 자산 이력 전체
- 예상 데이터: 기준월 다음 달부터 36개월
- 종료: 기준월 + 36개월

기존 수입 추세·저축 및 잔여율 예측식을 그대로 사용하며, 그래프의 표시 기간만 Roadmap과 일치시킨다.

## 홈 이동

데스크톱 사이드바의 로고와 `NetVisualizer` 제목을 하나의 버튼으로 묶고 기존 `switchView('dashboard-view')` 경로를 사용한다. 별도 URL 이동이나 새로고침은 하지 않는다.

## 키보드 이동

- 앱 전역 `keydown` 화살표 내비게이션을 제거한다.
- 전략 보유카드의 `tabindex="0"`을 제거한다.
- 입력·버튼 등 기본 접근성 포커스는 유지한다.

## Step 표시

- 사용자 노출 명칭은 모두 `Step`으로 통일한다.
- 상세 패널은 `renderStepEditor()`의 단일 목록만 렌더링한다.
- 별도의 저장된 Step 목록을 다시 출력하지 않는다.
- 입력 버튼과 Enter 처리는 동일 이벤트의 중복 실행을 막도록 즉시 전파를 중단한다.

## 데이터 영향

- `steps` JSON 구조와 Step ID는 유지한다.
- 포트폴리오 전략 정의 및 전략 태그는 변경하지 않는다.
- DB 마이그레이션은 없다.
