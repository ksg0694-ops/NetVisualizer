# Update 1.04.03 Note Workspace Design

## 저장 계약

- Todo 본문은 기존 `life_todos.note` 일반 문자열을 유지한다.
- 기존 `**굵게**`, `++밑줄++`, `~~취소선~~`, `- [ ]`, `{{icon:key}}` 토큰과 호환한다.
- 신규 블록은 Markdown 호환 토큰(`#`, `> [!NOTE]`, `---`, 표)을 사용한다.
- 버전 기록은 별도 localStorage 키에 보관해 기존 Supabase 스키마를 변경하지 않는다.
- 학습 노트 본문과 계층 필드는 기존 `learning_archive_notes` 계약을 유지한다.

## 할 일 편집기

- 상단 툴바에 인라인 서식, 블록, 연결 기능을 묶는다.
- 빈 줄에서 `/`를 입력하거나 블록 버튼을 누르면 블록 메뉴를 연다.
- 선택 문장 전환은 원문을 삭제하지 않고 새 할 일 또는 Step을 생성한다.
- 자동 저장은 입력 정지 후 debounce로 로컬 저장하고, 가능한 경우 기존 Supabase upsert를 호출한다.
- 최근 버전은 헤더의 `버전 기록` 버튼에서 열고 복원할 수 있다.

## 학습 아카이브 레이아웃

- 데스크톱: `280px 계층 목록 / minmax(520px, 1fr) 편집기 / 280px Context Dock`.
- 왼쪽은 분야와 항목을 폴더, Chapter를 하위 그룹, 노트를 문서 행으로 표현한다.
- 오른쪽 독은 연결·버전·목차 탭으로 전환한다.
- 1280px 미만에서는 Context Dock을 편집기 아래로 이동하고, 모바일에서는 선택한 노트 편집기를 우선 표시한다.

## 연결 규칙

- `[[노트 제목]]`을 명시적 노트 링크로 해석한다.
- 현재 노트를 링크한 다른 노트를 역링크로 표시한다.
- Todo 제목/본문과 학습 노트의 제목·태그 간 키워드가 겹치면 관련 할 일로 표시한다.
- 관련 할 일의 Step 및 Report 링크를 같은 Context Dock에서 탐색한다.

## 안전 및 호환성

- 사용자 입력은 HTML로 직접 저장하지 않고 문자열 토큰으로 직렬화한다.
- 렌더링 시 기존 escape 유틸을 사용하고 외부 Report 링크는 기존 URL 검증 결과만 연다.
- 원격 신규 컬럼에 의존하지 않아 미적용 Supabase 환경에서도 저장 기능이 유지된다.
