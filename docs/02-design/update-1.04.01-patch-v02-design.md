# Update 1.04.01 patch v02 설계

## 내비게이션

- `life-view` 화면을 앱 표면에서 제거한다.
- 데스크톱의 생활 영역 버튼은 `routine-checklist-view`로 직접 이동한다.
- 모바일은 헤더의 메뉴 버튼으로 전체 탭 메뉴를 연다.
- 모바일의 상단 영역 칩과 고정 하단 탭은 제거해 콘텐츠 높이를 확보한다.
- 기존 `life-view` 이동 요청은 호환성을 위해 할 일 화면으로 리다이렉트한다.

## 할 일 상태와 삭제

- `open` 저장값과 필터 키는 호환성을 위해 유지하고 사용자 표기만 `진행 중`으로 바꾼다.
- 완료 항목은 `완료` 필터에서 보관하고 원형 완료 버튼으로 다시 진행 중 상태로 되돌릴 수 있다.
- 일괄 완료 삭제는 제거하고 카드별 삭제만 유지한다.

## 서버 동기화

- 인증된 서버 조회가 성공하면 `life_todos` 응답을 해당 사용자의 기준 목록으로 취급한다.
- 서버 목록과 오래된 로컬 캐시를 병합하지 않는다. 이 병합이 다른 기기에서 삭제된 항목을 다시 upsert하던 원인이었다.
- 개별 삭제는 로컬에서 먼저 반영하되 서버 삭제가 실패하면 직전 목록을 복원하고 실패 상태를 알린다.
- 로그아웃·오프라인에서는 기존 로컬 저장 동작을 유지한다.

## 모바일 폼

- 새 할 일 폼과 상세 편집 폼은 모바일에서 화면 전체를 사용하는 다이얼로그로 표시한다.
- 제목 영역과 저장 영역은 고정하고 본문만 스크롤한다.
- 데스크톱에서는 기존 목록·상세 2열 배치를 유지한다.
- 상세 미선택 안내 패널은 모바일에서 숨겨 불필요한 빈 높이를 없앤다.

## 로그인 피드백

- `auth-feedback`을 로그인 입력 및 버튼과 같은 카드 안에 둔다.
- 이메일·비밀번호 검증, 로그인 링크 전송, 로그인·가입 성공과 실패를 같은 영역에 표시한다.
- `role="alert"`와 `aria-live="assertive"`로 오류가 보조기술에도 즉시 전달되게 한다.
