# 미래 예상자산 기준 월급 수정 설계

## 관측 구간

- 선택 월 이하의 회계구간 중 `period.endDate < today`인 구간만 사용한다.
- 총수입이 있더라도 급여성 수입 이벤트가 없으면 월급 관측치에서 제외한다.
- 현재 진행 중인 회계구간은 Monthly Report에는 표시하지만 장기 예측에는 반영하지 않는다.

## 급여 이벤트 정규화

- 급여성 수입: `type = 수입`이고 카테고리와 메모 결합값에 `급여` 또는 `월급`이 포함된 거래
- 의미상 중복 키: `date + abs(amount)`
- 중복 제거 후 한 회계구간에 여러 급여성 수입이 있으면 가장 작은 금액을 기본 월급으로 사용한다.
- 별도 상여는 기존 설·추석 상여 달력 규칙으로 계산하므로 기본 월급 합계에 더하지 않는다.

## 안전장치

- 서버 원본 거래와 Monthly Report 합계는 변경하지 않는다.
- 예측 입력만 정규화한다.
- 급여 이벤트가 하나도 없으면 전체 수입으로 대체하지 않고 예측 데이터 부족 상태를 유지한다.
- 중복 급여와 완료 구간 필터를 자동 테스트로 고정한다.
