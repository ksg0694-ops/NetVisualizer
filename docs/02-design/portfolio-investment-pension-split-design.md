# 투자자산·연금 상세 분리 설계

## 데이터 범위

`FinanceModel.buildCfoAssetGroups()`의 분류 결과를 상세 화면의 단일 기준으로 사용한다.

| 상세 범위 | CFO 그룹 키 | 포함 데이터 |
|---|---|---|
| 투자자산 | `investment` | 일반 증권·ISA·CMA 등 투자 목적 보유항목 |
| 연금 | `pension` | 연금저축·IRP·퇴직연금 등 연금 목적 보유항목 |

원본 `group_name`은 계좌·출처 표시를 위해 유지한다. 상세 화면의 계산 범위는 원본 그룹명이 아니라 CFO 그룹 키로 결정한다.

## 화면 동작

1. 포트폴리오 자산군 목록에서 `투자자산` 또는 `연금`의 상세보기를 선택한다.
2. 선택한 CFO 그룹 키를 `activeInvestGroupName`에 저장한다.
3. 평가금액, 손익, 전략 보드, 보유종목 편집기, 전략별 수익률, 차트에 같은 항목 배열을 전달한다.
4. 저장 또는 현재가 갱신 후에도 활성 CFO 그룹 키로 다시 렌더링한다.

## 호환성

- 기존 `renderInvestDetail()` 함수명은 유지한다.
- 과거 호출값인 `투자 자산`과 `연금`도 CFO 그룹 키로 정규화한다.
- 전략 정의와 개별 `strategy_tag`는 공유하므로 기존 드래그 이동 및 이름 변경 기능을 그대로 사용한다.
- DB 스키마 변경은 없다.

## 검증 포인트

- 투자자산과 연금 상세 버튼 모두 존재
- 전략 보드와 보유종목 편집기가 전체 포트폴리오 재탐색을 하지 않음
- 현재가 자동 갱신 ticker가 활성 자산군으로 제한됨
- 상세 화면 제목·합계 라벨·전략 비중 라벨이 선택 범위를 반영
