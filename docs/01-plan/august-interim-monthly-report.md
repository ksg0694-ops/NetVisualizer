# 8월 중간현황 Monthly Report 계획

## 보고 목적

- 질문: 8월 급여주기 중 현재 재무 흐름이 어디까지 진행됐고, 소비·저축 흐름이 직전 기간과 비교해 어떤 상태인가?
- 독자: NetVisualizer 소유자
- 범위: 선택된 급여주기 월, 우선 적용 대상은 2026년 8월
- 비교 기준: 직전 급여주기의 일평균 소비
- 성공 기준: Monthly Report 첫 화면에서 데이터 최신성, 진행률, 소비 속도, 저축+잔여, 최대 소비 분야를 바로 파악한다.

## 요구사항

1. 별도 탭을 만들지 않고 Monthly Report 상단에 중간현황을 추가한다.
2. 선택한 월이 진행 중이면 `중간현황`, 종료됐으면 `마감현황`으로 자동 전환한다.
3. 데이터 최신일과 급여주기 경과일을 분리해 보여준다.
4. 소비는 상환을 제외한 지출로 정의한다.
5. 현재 일평균 소비를 직전 기간 일평균 소비와 비교한다.
6. 저축+잔여는 실제 수입이 있을 때만 수입 대비 비율을 표시한다.
7. 최대 소비 분야와 해당 금액을 표시한다.
8. 기존 현금흐름·장기 목표·포트폴리오 차트는 증거 화면으로 유지한다.

## 완료 조건

- 2026년 8월을 선택하면 `8월 중간현황`이 표시된다.
- 최신 거래일, 거래 건수, 기간 진행률이 실데이터에서 계산된다.
- 직전 기간 데이터가 없을 때 비교 문구가 오해 없이 대체된다.
- 데스크톱 한 화면의 compact 방향을 유지하고 모바일에서 가로 넘침이 없다.
- 전체 자동검사와 실제 배포 페이지 검증을 통과한다.
