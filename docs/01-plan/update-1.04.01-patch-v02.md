# Update 1.04.01 patch v02 계획

## 목표

- 생활 홈을 제거하고 생활 영역에서 할 일로 바로 이동한다.
- 모바일 탭 이동을 고정 하단 탭 대신 상단 메뉴 버튼과 독립 메뉴 창으로 바꾼다.
- 완료한 할 일을 보관·재사용할 수 있도록 일괄 삭제 기능을 제거한다.
- 다른 기기에서 삭제된 할 일이 로컬 캐시 때문에 다시 생성되지 않도록 서버 동기화 기준을 바로잡는다.
- 로그인 실패 메시지를 로그인 폼 안에서 바로 확인할 수 있게 한다.

## 적용 범위

1. 생활 홈 화면과 연결 제거
2. 모바일 탭 메뉴 다이얼로그 추가 및 하단 탭 제거
3. `열림`을 `진행 중`으로 변경
4. `완료 항목 지우기` 제거, 개별 삭제와 완료 취소 유지
5. 로그인 사용자의 할 일 서버 목록을 동기화 기준값으로 사용
6. 서버 삭제 실패 시 로컬 항목 복원
7. 모바일 새 할 일·상세 편집을 독립 전체화면 폼으로 전환
8. 로그인 입력 검증·실패·성공 메시지를 폼 내부에 표시

## 제외 범위

- 기존 할 일 또는 Step 데이터 일괄 변경
- 완료 항목 자동 재개 규칙
- 건강 기능 재활성화
- 재무 탭 구조 변경

## 완료 기준

- 생활을 선택하면 생활 홈을 거치지 않고 할 일이 열린다.
- 모바일에서 메뉴 버튼으로 모든 활성 탭을 선택할 수 있다.
- 모바일 할 일 상세가 목록 아래가 아니라 독립 폼으로 열린다.
- 완료 항목 일괄 삭제 버튼이 없고 완료 취소는 계속 가능하다.
- 다른 기기에서 서버 삭제된 항목이 새로고침 뒤 복원되지 않는다.
- 로그인 실패 문구가 로그인 카드 안에 표시된다.
- 자동검사와 데스크톱·390×844 모바일 검증이 통과한다.
