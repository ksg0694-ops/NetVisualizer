# 투자자산·연금 상세 분리 계획

## 목표

- 포트폴리오의 `투자자산`과 `연금`에서 각각 독립된 상세 화면으로 진입한다.
- 전략명과 전략 분류 체계는 공유하되, 보유종목·평가금액·수익률·전략 비중은 선택한 자산군 안에서만 계산한다.
- 기존 데이터와 전략 태그는 변경하지 않는다.

## 범위

1. 연금 자산군에 상세보기 진입 버튼 추가
2. 상세 화면 제목과 요약 문구를 선택 자산군에 맞게 변경
3. 전략 보드와 보유종목 편집기의 입력 범위를 선택 자산군으로 제한
4. 현재가 갱신 ticker 범위를 선택 자산군으로 제한
5. 자동 검사와 데스크톱·모바일 브라우저 회귀 검증
6. GitHub Pages 배포

## 제외 범위

- 전략 정의 및 전략 태그 변경
- 포트폴리오·연금 원본 데이터 변경
- 별도 DB 테이블 또는 마이그레이션 추가
- Update 1.04.02의 후속 요구사항 선반영

## 완료 기준

- 투자자산 상세에는 투자자산 항목만 표시된다.
- 연금 상세에는 연금 항목만 표시된다.
- 각 화면의 합계, 손익, 전략별 비중과 수익률이 동일한 범위에서 계산된다.
- 투자자산과 연금 사이에 동일 보유항목이 중복 표시되지 않는다.
- 전체 자동 검사와 주요 화면 회귀 검사가 통과한다.
