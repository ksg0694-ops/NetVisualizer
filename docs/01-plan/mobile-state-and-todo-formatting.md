# Mobile state and Todo formatting plan

## Goal

모바일에서 앱을 백그라운드로 보낸 뒤 프로세스가 다시 로드되어도 사용자가 보던 위치를 이어서 사용하고, 할 일 목록의 영역 구분과 상세내역 서식을 다시 명확하게 만든다.

## Scope

1. 마지막 활성 탭과 선택 월을 기기에 저장한다.
2. 할 일 필터, 영역 필터, 선택한 할 일을 기기에 저장한다.
3. Career, Finance, Life 카드에 낮은 채도의 영역 색상을 적용한다.
4. 상세내역과 신규 할 일 입력에 굵게, 밑줄, 취소선 도구와 안전한 미리보기를 제공한다.
5. PWA 캐시 버전을 올리고 모바일 복귀 시나리오를 검증한다.

## Non-goals

- 저장하지 않은 상세내역 초안의 자동 저장
- 운영체제의 강제 종료 자체를 막는 네이티브 앱 기능
- 사용자 입력 HTML을 그대로 저장하거나 실행하는 리치 텍스트 편집기

## Acceptance criteria

- 할 일 상세를 연 상태에서 페이지가 다시 로드되어도 동일한 탭과 상세가 열린다.
- 할 일 카드는 영역별 배경색으로 빠르게 구분된다.
- B/U/S 버튼이 선택 영역을 각각 `**`, `++`, `~~`로 감싸고 미리보기에 서식을 표시한다.
- 서식 미리보기는 사용자 입력을 먼저 이스케이프해 HTML 실행을 허용하지 않는다.
- 전체 애플리케이션 검사와 모바일 브라우저 검증을 통과한다.
