# Update 1.04.01 구현 계획

## 목표

현재 탭 구조를 검토하고 포트폴리오 전략, 단기 Roadmap, 할 일 선택·완료 UX를 사용자가 직접 관리할 수 있게 확장한다.

## 범위

### 포트폴리오

- 기존 여섯 전략은 유지하되 전략 박스를 추가할 수 있게 한다.
- 전략의 저장 키는 유지하고 화면 이름만 변경할 수 있게 한다.
- 전략별 수익률을 전략 박스 머리에서 바로 확인할 수 있게 한다.
- 전략 추가·이름 변경은 Supabase에 저장해 기기 간 동일하게 보이게 한다.

### 단기 Roadmap

- 상대적인 12·24·36개월 대신 `2026 / 2027 / 2028` 달력연도로 고정한다.
- 각 연도 말 예상 자산을 현재 수입 추세로 계산한다.
- 연도별 목표 자산을 직접 입력하고 저장할 수 있게 한다.
- 목표 대비 예상 달성률과 부족·초과 금액을 표시한다.

### 할 일

- 새 할 일과 상세 편집의 영역 선택을 Career·Finance·Life 세 버튼 중 하나를 고르는 방식으로 변경한다.
- 목록의 완료 컨트롤은 Google Calendar 할 일처럼 제목 왼쪽의 작은 원형 버튼 하나로 단순화한다.
- 저장 데이터와 기존 할 일·스텝 완료 상태는 유지한다.

## 탭 검토 기준

- 재무 탭 순서와 역할은 `Monthly Report / 현금흐름 / 포트폴리오 / 장기 목표 / 개인 CFO`로 유지한다.
- 비활성화된 건강 탭은 계속 노출하지 않는다.
- 이번 패치는 새 최상위 탭을 추가하지 않고 기존 포트폴리오·장기 목표·할 일 안에서 기능을 확장한다.

## 완료 조건

- 사용자 정의 전략을 추가하고 새 박스로 즉시 표시할 수 있다.
- 전략 이름 변경 후 새로고침해도 이름이 유지된다.
- 전략 박스마다 비교 가능한 종목 기준 합산 수익률이 표시된다.
- Roadmap이 2026·2027·2028을 표시하고 연도별 목표를 저장한다.
- 영역 선택은 세 버튼 중 하나만 활성화된다.
- 목록 완료 컨트롤은 원형 버튼 하나이며 기존 완료 저장이 동작한다.
- 전체 자동검사와 모바일·데스크톱 실제 브라우저 검증을 통과한다.
