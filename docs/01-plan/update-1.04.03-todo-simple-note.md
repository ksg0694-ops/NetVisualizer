# Update 1.04.03 Todo Simple Note — Plan

## Goal

Reduce the Todo detail note to a stable memo-first editor for immediate weekly use.

## Scope

- Remove note checkbox, inline icon, block, Todo conversion, and Step conversion controls.
- Preserve ordinary memo text, B/U/S formatting, Tab indentation, autosave, versions, and manual save.
- Preserve Todo status, existing Step management, Report Library, and all stored task data.
- Render legacy special syntax as ordinary editable text instead of deleting it.

## Quality gate

- Static UI contracts pass.
- Full repository check passes.
- Browser QA confirms the advanced controls are absent and retained Todo features remain visible.
