# Update 1.04.03 Learning Archive Simple Memo Plan

## Goal

Return Learning Archive to a reliable memo-first editor for immediate weekly use.

## Remove

- Checklist controls and interactive checkbox rendering.
- Inline icon and callout-icon features.
- Block menu and block transformations.
- Todo and Step conversion controls.
- Related Todo, Step, and task-derived Report context.

## Keep

- Existing note data without destructive migration.
- Field, item, Chapter, title, and body editing.
- Basic bold, underline, and strike formatting.
- Text selection, indentation, autosave, manual save, versions, links, and ordering.

## Acceptance criteria

- Existing advanced syntax appears as ordinary editable text.
- The editor toolbar contains only B, U, and S.
- No Learning Archive code references Checklist features.
- The complete repository check suite passes.
