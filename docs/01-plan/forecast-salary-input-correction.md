# 미래 예상자산 기준 월급 수정 계획

## 문제

예측 로직이 수입이 있는 모든 회계구간을 월급 관측치로 사용한다. 데이터가 월 중간부터 시작한 2025년 8월 구간의 전체 수입 466,938원이 최저 월급으로 선택되어 3년 예상자산이 과소 계산된다.

2026년 2~6월에는 같은 날짜와 금액의 급여성 수입이 두 번씩 존재해 급여 합계도 왜곡된다.

## 목표

1. 종료일이 지난 완료 회계구간만 예측에 사용한다.
2. 급여 또는 월급으로 확인되는 실제 수입 이벤트가 있는 구간만 사용한다.
3. 같은 날짜와 금액의 급여 이벤트는 예측 입력에서 한 건으로 처리한다.
4. 한 구간에 일반 급여와 별도 상여가 함께 있으면 가장 작은 급여 이벤트를 기준 월급 후보로 사용한다.
5. 원본 서버 거래는 삭제하거나 수정하지 않는다.
6. 현재 서버 데이터에서 2026~2028년 예상자산을 다시 검증한다.
