# Update 1.04.01 수정패치 v1 계획

## 목표

- 기존 포트폴리오 전략 관리 기능을 보존하고 정상 작동을 재검증한다.
- 장기 목표의 자산 추세 그래프를 현재 기준 향후 36개월까지 확장해 `단기 Roadmap 3년`과 기간을 맞춘다.
- 앱 내 불필요한 키보드 이동과 중복 Step 표시를 제거한다.

## 적용 범위

1. 전략박스 추가·이름 변경·전략별 수익률 회귀검사
2. 자산 추세 그래프: 최초 데이터부터 현재 기준 향후 36개월까지 표시
3. `NetVisualizer` 제목 클릭 시 재무 홈 이동
4. 전역 화살표키 화면·월 이동 제거
5. 전략 카드의 강제 키보드 탭 진입 제거
6. 할 일 화면의 `스텝`, `하위 할 일`, `Sub tasks` 표기를 `Step`으로 통일
7. 상세 화면에서 동일 Step 목록이 두 번 표시되는 구조 제거

## 제외 범위

- 포트폴리오 전략 데이터 변경
- 연도별 Roadmap 목표값 변경
- 할 일 또는 Step 서버 데이터 일괄 변경
- Update 1.04.02 요구사항 선반영

## 완료 기준

- 자산 추세 그래프의 마지막 월이 기준월 + 36개월이다.
- 앱 제목으로 재무 홈에 이동할 수 있다.
- 화살표키로 화면이나 월이 바뀌지 않는다.
- 전략 보유카드가 강제로 탭 순서에 들어가지 않는다.
- 할 일 화면의 사용자 노출 명칭이 `Step`으로 통일된다.
- 신규 또는 기존 Step이 상세 화면에 한 번만 표시된다.
- 전체 자동검사와 데스크톱·모바일 검증이 통과한다.
