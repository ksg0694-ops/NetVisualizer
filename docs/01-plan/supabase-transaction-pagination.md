# Supabase 거래 전체조회 수정 계획

## 문제

서버에는 거래 2,286건과 최신 거래일 2026-08-02가 존재하지만, 앱은 Supabase 기본 응답 한도 1,000건만 가져와 최신 거래가 화면에서 누락된다.

## 목표

1. 거래 테이블 조회를 1,000행 단위로 반복한다.
2. 마지막 페이지가 1,000행보다 작을 때 조회를 종료한다.
3. 기존 정렬, 선택 컬럼, optional table 오류 처리를 보존한다.
4. 1,000건을 초과하는 회귀 테스트를 추가한다.
5. 배포 후 로그인 세션에서 최신 거래일과 8월 Monthly Report를 확인한다.
