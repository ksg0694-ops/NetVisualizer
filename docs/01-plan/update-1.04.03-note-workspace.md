# Update 1.04.03 Note Workspace Plan

## 목표

- 기존 `할 일` 3열 작업대는 유지하고 중앙 상세내역을 블록형 노트 편집기로 확장한다.
- `학습 아카이브`는 계층형 목록과 Context Dock을 결합하고 PC 가로 공간을 넓게 사용한다.
- 노트에서 문장을 `할 일` 또는 `Step`으로 전환해 기록과 실행을 연결한다.
- 자동 저장과 로컬 버전 기록으로 긴 글 작성 중 손실 위험을 줄인다.

## 범위

### 할 일

- 제목, 체크박스, 강조, 구분선, 표 블록을 `/` 메뉴에서 삽입
- 선택 문장 또는 현재 줄을 새 할 일/현재 할 일의 Step으로 전환
- 편집 중 자동 저장 상태와 최근 버전 목록 제공
- Career / Finance / Life 목록, 중앙 편집기, Report Library의 3열 구조 유지

### 학습 아카이브

- `공부 분야 → 공부 항목 → Chapter → 노트` 4단계 목록을 왼쪽에 표시
- 중앙 편집기 폭을 우선 확보하고 오른쪽에 `연결 / 버전 / 목차` Context Dock 배치
- `[[노트 제목]]` 링크와 역링크, 관련 할 일/Step/Report 표시
- 노트 편집 중 자동 저장 및 버전 복원

## 제외 범위

- 새로운 인증 체계 또는 별도 백엔드 서비스 도입
- 첨부 파일 업로드 재도입
- 저장된 기존 Todo, Report, Learning Archive 데이터의 파괴적 변환

## 완료 조건

- 기존 데이터가 그대로 열리고 수정·저장된다.
- 데스크톱에서 두 선택 시안의 핵심 3열 구성이 재현된다.
- 모바일에서는 단일 열 또는 전체 화면 편집으로 가로 넘침이 없다.
- `npm run check`와 참조 이미지 대비 디자인 QA를 통과한다.
