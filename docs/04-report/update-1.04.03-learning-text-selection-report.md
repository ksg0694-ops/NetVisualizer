# Update 1.04.03 Learning Archive Text Selection Report

## Result

Learning Archive now preserves multi-character and multi-line pointer selections instead of collapsing them during the click event that follows pointerup.

## User impact

- Text can be dragged across and selected normally.
- Normal single-click caret placement remains precise.
- Existing keyboard selection and editing controls remain available.

## Release

- Learning Archive asset query advanced to `update-10403-7`.
- Application cache advanced to `v167`.
