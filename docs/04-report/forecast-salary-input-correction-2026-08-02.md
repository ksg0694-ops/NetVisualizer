# 미래 예상자산 기준 월급 수정 완료 보고

## 결과

- 진행 중인 회계구간을 장기 예측에서 제외했다.
- 급여성 수입 이벤트가 없는 구간을 월급 후보에서 제외했다.
- 같은 날짜와 금액의 급여 이벤트는 예측 입력에서 한 건으로 처리했다.
- 같은 구간에 정기급여와 별도 상여가 있으면 작은 정기급여를 월급 후보로 사용했다.
- Supabase 원본 거래와 Monthly Report 거래 합계는 변경하지 않았다.
