# Update 1.04 완료 보고서

## 결과

Update 1.04의 포트폴리오 전략 분류, 3년 단기 Roadmap, 건강 탭 비활성화, 할 일 UX 개편을 구현하고 Supabase 데이터까지 마이그레이션했다.

## 포트폴리오 전략

- 전략 축을 `현금대기 / 원자재 / 배당주 / 가상화폐 / 금융주 / AI(반도체)` 여섯 개로 고정했다.
- 기존 CFO 목적 그룹인 `운영 / 안전 / 투자 / 주거 / 연금`은 별도 축으로 유지했다.
- 전략 칸 안에서는 원화 평가액이 큰 자산부터 정렬한다.
- 데스크톱은 드래그, 모바일·키보드는 선택 메뉴로 전략을 변경한다.
- 화면을 먼저 이동한 뒤 Supabase에 저장하고, 실패하면 기존 전략으로 복구한다.
- 전략 변경은 `portfolios.strategy_tag`만 수정하므로 수량·평균매입단가·현재가·환율·CFO 목적 그룹은 유지된다.

## 3년 단기 Roadmap

- 장기 목표의 수입 추세 계산을 재사용해 현재 기준월 다음 달부터 36개월을 계산한다.
- 관찰 기간 중 가장 낮은 월급으로 기준 급여를 잡고 설날·추석 상여를 반영한다.
- 월 예상 수입에 관찰된 저축+잔여 중앙비율을 적용한다.
- 화면에는 12개월, 24개월, 36개월 체크포인트를 표시한다.

검증 시 예상 자산은 각각 2027-07 `259,167,318원`, 2028-07 `282,705,780원`, 2029-07 `306,244,242원`이었다. 입력 데이터가 바뀌면 동일 계산식으로 자동 갱신된다.

## 비활성화

다음 기능은 계산 코드와 저장 데이터는 보존하고 화면 진입만 비활성화했다.

- 건강 탭과 모바일 건강 메뉴
- Quant 전략 구조
- MDD 방어 상태
- 원화 평가 기준 설명

비활성화된 건강 경로로 접근하면 생활 홈으로 이동한다.

## 할 일 UX

- 영역 입력과 영역 필터를 단일 선택 메뉴로 변경했다.
- 목록에는 제목·영역·스텝 진행률만 표시한다.
- 날짜 입력, 날짜 표시, 오늘 마감, 기한 지남 필터를 제거했다.
- 상세내역은 상세 화면에서만 표시한다.
- 스텝 입력 단계부터 순서와 개별 완료 여부를 관리하며 `{ id, title, done, createdAt }[]` 구조를 유지한다.
