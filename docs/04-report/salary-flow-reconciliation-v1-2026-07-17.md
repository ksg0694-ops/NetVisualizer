# 급여기간 정산 원장 v1 완료 보고

## 적용 결과

- 급여일 내부 이체를 같은 날짜·금액·시간 기준으로 짝지었다.
- 청년도약계좌 출금·입금을 한 건으로 계산한다.
- 대출통장 선입금과 잔액 반환을 내부 이체로 제거하고 이자만 부채 현금흐름으로 남긴다.
- 생활비통장 유입과 월급통장 반환을 순액으로 계산한다.
- 짝 없는 월급통장 내부 이체를 원화 발행어음 흐름으로 추정한다.
- 거래 근거가 부족한 기간은 기존 목표 규칙으로 되돌린다.

## 검증

- 실제 급여일 거래 순서를 재현한 런타임 테스트 통과
- 내부 이체 6쌍 중복 없는 매칭 확인
- 생활비통장 순유입 317,693원 확인
- 월급통장 잔존액 270,348원 확인
- 생활비 합계 588,041원 확인
- 원화 발행어음 1,118,502원 확인
- 월급 배분 보존식 확인
- TypeScript, 도메인, repository, UI, Supabase, 정적 자산 검사 통과

## 남은 한계

- 원화 발행어음은 상대 계좌 정보가 없어 아직 추정이다.
- 통장별 급여 직전 잔액이 없어 목표 잔액 달성 여부를 직접 검증하지 못한다.
- 진행 중 기간에는 발행어음 거래가 없을 수 있어 목표 규칙으로 폴백한다.

## 다음 단계
