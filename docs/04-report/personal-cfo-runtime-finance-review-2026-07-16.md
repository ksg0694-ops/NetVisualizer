# Personal CFO 런타임 통합 및 재무 화면 검토

- 완료일: 2026-07-16
- 범위: 이전 보고서의 Next Step, 재무 홈, CFO Network, Supabase 포트폴리오·현금흐름 검토
- 인증: 사용자 결정에 따라 이번 범위에서 제외

## 결론

Personal CFO의 TypeScript 구현을 실제 브라우저 런타임으로 전환했다. 재무 네트워크는 하나의 복합 그래프보다 `재무상태`, `현금 흐름`, `목표·리스크` 세 화면으로 나누는 구조가 현재 데이터에 가장 적합하다.

재무 홈은 네트워크 탐색 화면이 아니라 현재 상태와 다음 행동을 판단하는 화면으로 유지했다. 순자산, 최근 마감 현금흐름, 목표자산, 청약 자기자금 순으로 읽히도록 정리했다.

## 재무 홈 변경

1. 최근 마감 잉여현금 카드를 추가하고 수입·지출을 함께 표시했다.
2. 마지막 거래일과 경과일을 표시해 데이터 신선도를 판단할 수 있게 했다.
3. 청약 준비율을 `청약 자기자금`으로 바꿨다.
4. 자기자금은 현금·안전자산 + 주거자산 + 투자자산 90% - 부채로 계산하고 연금은 제외했다.
5. 현재 자기자금은 224,067,575원, 8억원 목표 대비 28.0%다. 대출 가능액은 저축한 돈으로 합산하지 않는다.
6. 부동산 DSR 가정은 미마감 월과 성과급을 제외한 마감월 급여 중앙값을 연환산하고, 최근 마감월 원리금 상환을 기존 월 부채로 사용한다. 사용자가 저장한 override가 있으면 그 값이 우선한다.

이 변경으로 홈의 청약 숫자는 작아졌지만 실제로 동원 가능한 자기자금과 대출 여력을 구분해 판단할 수 있다.

## CFO Network 구조

### 재무상태

기본 화면이다. 잔액 시점이 같은 계좌, 자산, 부채만 표시한다. 월급에서 계좌잔액으로 흐르는 것처럼 보이던 잘못된 엣지를 제거했다. 전세금 1.4억원은 기타가 아니라 주거자산으로 분류된다.

### 현금 흐름

최근 마감월만 사용한다. 2026년 6월 수입 390.9만원이 실제 지출·저축 바구니, 부채상환 126.9만원, 저축 후 미배분 30만원으로 나뉜다. 유입액과 모든 유출 엣지 합계가 일치하도록 테스트한다.

### 목표·리스크

운영·방어·주거·성장·인적자본·경험 바구니가 두 프로젝트와 리스크에 연결되는 계획 화면이다. 프로젝트는 부동산 청약 준비와 온라인 석사 준비만 유지한다. 이 화면의 바구니 잔액·리스크 노출액은 아직 수동 계획값이다.

세 네트워크 모두 세로열을 고정했다. 현금흐름과 목표·리스크는 자금 바구니별 수평 레인도 사용한다. 같은 레인의 연결은 직선으로, 레인이 다른 연결은 수직·수평 직교선으로 표시하며 열 제목과 보조선을 추가했다.

## 코드 구조 개선

- `src/features/personal-cfo/`가 타입, mock, 계산, 포트폴리오 어댑터, 현금흐름 어댑터, 그래프 생성의 단일 소유자가 됐다.
- Vite가 `js/generated/personal-cfo-domain.js`를 생성하고 정적 PWA가 이를 먼저 로드한다.
- `personalCfo.js`는 렌더링과 저장 동기화만 담당한다.
- 사용되지 않던 JS mock·계산·분류·그래프 중복을 제거해 약 1,300줄에서 744줄로 줄였다.
- `npm run check:cfo-runtime`에 미마감 기간 제외, 전세금 분류, 실제 상환액, 모드 분리, 현금흐름 보존 테스트를 추가했다.

## 검증

- `npm.cmd run check`: 전체 통과
- 데스크톱: 재무 홈과 3개 CFO Network 모드 실제 데이터 렌더 확인
- 모바일 390x844: 가로 넘침 없음, 복잡한 그래프 대신 자산·부채·마감월 바구니 요약 표시
- 브라우저 런타임 오류 없음
- 기존 Tailwind CDN 운영 경고만 남음

## 남은 판단과 다음 순서

1. `appCore.js`의 2차원 배열을 `FinanceRepository` 객체 경계로 교체한다.
2. 거래 분류 규칙을 사용자가 수정할 수 있는 월간 CFO 마감 기능을 만든다.
3. 비상금 커버리지, 프로젝트 자금, 리스크 노출액을 실제 데이터 또는 명시적 계획 입력으로 분리한다.
4. 90일 현금 전망은 월간 마감과 반복 거래 규칙이 안정된 뒤 추가한다.
5. 공개 배포 전 Tailwind CDN과 익명 Supabase 정책을 정리한다.

제품 방향은 계속 `Finance-first Personal OS`가 적합하다. 재무 홈은 오늘의 판단과 행동을, CFO Network는 잔액·흐름·전략의 관계를 탐색하는 보조 도구를 담당한다.
