# Update 1.04.03 Todo Simple Note — Report

## Outcome

The Todo detail editor is now a memo-first surface matching the Learning Archive simplification.

## Removed

- Inline checklist creation and interactive note checkboxes
- Inline icon picker and icon rendering
- Slash block menu and block transformations
- Memo-to-Todo and memo-to-Step conversion

## Retained

- Todo tab, status, domains, completion, and Monitor behavior
- Existing Step management and stored Step data
- Report Library
- B/U/S, Tab indentation, autosave, manual save, and note versions
- Stored memo content, including former special syntax as ordinary text
