# 투자자산·연금 상세 분리 완료 보고서

## 결과

포트폴리오의 투자자산과 연금을 같은 상세 기능 안에서 서로 독립된 계산 범위로 분리했다. 전략 정의와 전략 태그는 유지했으며 데이터 변경이나 DB 마이그레이션은 수행하지 않았다.

## 적용 내용

- 투자자산과 연금 자산군에 각각 `상세보기` 제공
- 선택한 CFO 그룹 키를 상세 화면의 단일 데이터 범위로 사용
- 화면 제목, 평가금액 라벨, 손익 라벨, 전략 비중 라벨을 선택 자산군에 맞게 변경
- 전략 보드, 보유종목 편집기, 전략별 수익률, 차트가 같은 범위의 항목만 사용
- 현재가 자동 갱신 ticker 범위를 활성 자산군으로 제한
- 저장·새로고침 후에도 투자자산 또는 연금 상세 범위를 유지
- PWA 캐시 버전을 갱신해 배포 후 최신 스크립트가 즉시 반영되도록 처리

## 검증

- 전체 `npm run check` 13단계 통과
- 투자자산 상세: 전략 보드 23개, 상세 카드 23개
- 연금 상세: 전략 보드 6개, 상세 카드 6개
- 데스크톱 1280×720: 가로 넘침 없음, 콘솔 오류 없음
- 모바일 390×844: 가로 넘침 없음, 콘솔 오류 없음
- 모바일 상단 제목이 `투자자산 상세`와 `연금 상세`로 구분됨

## 데이터 영향

- 전략 태그 변경 없음
- 전략 정의 변경 없음
- Supabase 스키마 변경 없음
