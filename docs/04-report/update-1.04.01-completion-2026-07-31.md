# Update 1.04.01 완료 보고서

## 탭 분류 검토

최상위 재무 탭은 현재 역할이 겹치지 않아 기존 순서를 유지했다.

1. Monthly Report: 월 마감 결과
2. 현금흐름: 거래와 재무 배분
3. 포트폴리오: 자산 목적 그룹과 투자 전략
4. 장기 목표: 자산 예상과 주거 가용자금, 단기 3년 목표
5. 개인 CFO: 현금흐름과 재무상태 통합 구조

건강 탭은 계속 비활성화했다. 이번 기능은 포트폴리오·장기 목표·할 일 안에 배치해 새 최상위 탭을 만들지 않았다.

## 포트폴리오

- `전략 관리` 패널에서 새 전략 박스를 추가할 수 있다.
- 각 전략 이름을 입력창에서 변경할 수 있다.
- 이름 변경은 화면 라벨만 바꾸며 종목이 저장된 `strategy_tag`는 유지한다.
- 전략 박스 머리에 전략 전체 합산 수익률과 계산 가능 종목 수를 표시한다.
- 합산 수익률은 현재가와 평균매입단가가 모두 있는 종목만 사용한다.
- 새 전략과 이름 변경은 `portfolio_strategy_definitions`에 저장한다.

브라우저 검증 시 임시 전략 추가와 이름 변경을 완료한 뒤 임시 행을 삭제했다. 서버에는 기본 전략 여섯 개만 남아 있다.

## 단기 Roadmap

- 상대적인 1·2·3년차 대신 2026·2027·2028 달력연도를 표시한다.
- 2026년은 현재 기준월 다음 달부터 12월까지, 2027·2028년은 각각 12개월을 계산한다.
- 연도별 목표 자산을 입력하고 `목표 저장`으로 Supabase에 저장한다.
- 목표가 있으면 예상 달성률과 부족·초과 금액을 표시한다.
- 목표가 없으면 예상 자산과 증가액만 표시한다.

검증용 2026년 목표 저장 후 부족 금액 표시를 확인했으며, 검증 종료 후 목표를 다시 미설정으로 복원했다.

## 할 일

- 새 할 일과 상세 편집의 영역 입력을 Career·Finance·Life 세 버튼으로 변경했다.
- 세 버튼은 한 번에 하나만 선택되고 기존 `career / finance / life` 값으로 저장된다.
- 목록 완료 컨트롤을 제목 왼쪽의 작은 원형 버튼으로 변경했다.
- 완료 시 원이 인디고 색으로 채워지고 체크가 표시된다.
- 기존 할 일의 완료·원복 서버 저장을 실제로 확인했다.
