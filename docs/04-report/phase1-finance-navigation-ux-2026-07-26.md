# Phase 1 재무 탭 및 UX 수정

## 목적

재무 도구의 정보 구조를 Monthly Report, 개인 CFO, 현금흐름, 포트폴리오, 장기 목표 순서로 정리하고, 월 결산·CFO 구조·주거 목표의 중복 표현을 하나의 의사결정 화면으로 통합한다.

## 변경 결과

### Personal CFO

- KPI 카드 6개를 화면에서 제거했다.
- `개인 CFO 자금 구조`와 `현금흐름과 재무상태 통합 요약`을 하나의 구조 요약으로 통합했다.
- 고정되지 않는 월 수입, 소비, 잔여는 금액 대신 `금액 미표시`로 표시한다.
- 현재 기준이 분명한 상환 약 130만원, 저축 80만원 규칙과 실제 자산·부채·순자산만 금액으로 표시한다.
- 실제 월 결과는 Monthly Report에서 확인하도록 역할을 분리했다.

### Monthly Report와 현금흐름

- `월별 Report` 명칭을 `Monthly Report`로 변경했다.
- 상세 현금흐름을 별도 `현금흐름` 탭으로 분리했다.
- `이번 달 결산`과 `수입의 이동`을 막대차트·수입 도넛·지출 도넛이 있는 하나의 결산/배분 섹션으로 통합했다.
- `장기자산 진행률`과 `자산 흐름과 목표 경로`를 실제 자산, 수입 추세 기반 예상, 목표 자산이 함께 보이는 하나의 섹션으로 통합했다.
- Monthly Report에서 중복되던 월별 현금흐름 추이를 제거하고 Portfolio Phase 2 예정 공간만 남겼다.
- 상세 현금흐름에서는 월 마감 패널을 제거하고, 작은 높이의 `이번 달 재무 배분`을 수입·지출 위로 이동했다.

### 장기 목표

- 탭 이름과 화면 제목을 `장기 목표`로 변경했다.
- 과거 자산에서 목표까지 직선으로 연결하던 예측을 제거했다.
- 마감된 월의 수입 추세와 `저축+잔여` 중앙 비율을 사용해 다음 달 자산을 누적 예측한다.
- 수입 추세의 월 변동은 중앙 수입의 ±3%로 제한해 소수 월의 이상치가 장기 예측을 왜곡하지 않도록 했다.
- 기존 목표달성률·총 자산증가액·월평균 증가속도 KPI를 제거했다.
- 가용 자기자금, 주담대 가능액, 총 가용자금, 예상 DSR을 장기 목표 화면에 통합했다.
- Chart.js를 프로젝트 내부에 고정하고, 숨겨진 탭에서 0×0으로 초기화된 차트를 탭 전환 시 다시 측정하도록 수정했다.

### 부동산

- 독립 `부동산` 탭을 내비게이션에서 제거했다.
- 기존 자금·DSR 가정 설정은 `장기 목표`의 `주거 목표 가용자금` 카드에서 열 수 있도록 유지했다.

## 검증

- `npm.cmd run check` 전체 통과.
- 1366 × 768 데스크톱과 390 × 844 모바일 브라우저 시각 검증 통과.
- Monthly Report 월 이동 `2026년 7월 → 6월 → 7월` 통과.
- 장기 목표 가정 설정 모달 열기·닫기 통과.
- 탭 전환 후 Monthly Report와 장기 목표 차트 크기 복원 통과.
- 브라우저 애플리케이션 콘솔 오류 없음.
- 상세 근거는 프로젝트 루트 `design-qa.md`에 기록했다.

## 후속 범위

- Portfolio Phase 2는 보유수량, 시장가격, 환율, Port, 월말 스냅샷 구조 확정 후 별도 구현한다.
- 부동산 정책 변경에 따른 대출 가능 여부는 정책 데이터가 확정된 뒤 다시 계산한다.
