# Phase 1 재무 탭 및 UX 수정

## 목적

재무 도구의 정보 구조를 Monthly Report, 현금흐름, 포트폴리오, 장기자산, 부동산 순서로 정리하고, Personal CFO와 Monthly Report의 중복·왜곡된 표현을 제거한다.

## 변경 결과

### Personal CFO

- KPI 카드 6개를 화면에서 제거했다.
- `개인 CFO 자금 구조`와 `현금흐름과 재무상태 통합 요약`을 하나의 구조 요약으로 통합했다.
- 고정되지 않는 월 수입, 소비, 잔여는 금액 대신 `월별 변동`으로 표시한다.
- 현재 기준이 분명한 상환 약 130만원, 저축 80만원 규칙과 실제 자산·부채·순자산만 금액으로 표시한다.
- 실제 월 결과는 Monthly Report에서 확인하도록 역할을 분리했다.

### Monthly Report와 현금흐름

- `월별 Report` 명칭을 `Monthly Report`로 변경했다.
- 상세 현금흐름을 별도 `현금흐름` 탭으로 분리했다.
- Monthly Report는 1366 × 768 노트북 화면에서 월 결산, 배분, 현금흐름 추이, 장기자산 목표 경로, Portfolio Phase 2 공간을 한 화면에 표시한다.
- 상세 현금흐름은 월 마감, 카테고리, 거래 관리, 가져오기, 부가 기능을 유지한다.

### 장기자산

- 목표 경로 hover 시 `null` 값을 안전하게 제외하도록 tooltip을 수정했다.
- 목표 경로의 hover 선 두께와 점 반경을 고정해 예측선이 사라지지 않도록 했다.
- Finance Roadmap을 제거했다.

### 부동산

- 주요 분양 일정과 청약 지도를 제거했다.
- 지도 컨테이너가 없으면 Leaflet을 로드하지 않고 자금·DSR 분석만 렌더링한다.

## 검증

- `npm.cmd run check` 전체 통과.
- 1440 × 900 및 1366 × 768 브라우저 시각 검증 통과.
- Monthly Report 월 이동 통과.
- 장기자산 예측 구간 hover 및 tooltip 통과.
- 부동산 화면에서 애플리케이션 콘솔 오류 없음.
- 상세 근거는 프로젝트 루트 `design-qa.md`에 기록했다.

## 후속 범위

- Portfolio Phase 2는 보유수량, 시장가격, 환율, Port, 월말 스냅샷 구조 확정 후 별도 구현한다.
- 부동산 정책 변경에 따른 대출 가능 여부는 정책 데이터가 확정된 뒤 다시 계산한다.
