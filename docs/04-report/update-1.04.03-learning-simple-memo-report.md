# Update 1.04.03 Learning Archive Simple Memo Report

## Result

Learning Archive is now a memo-first editor with the advanced checklist, icon, block, Todo, and Step feature set removed.

## User impact

- Notes open as ordinary editable text.
- Existing note content is preserved.
- The toolbar is reduced to B, U, and S.
- Autosave, manual save, versions, links, search, and ordering remain.

## Release

- Learning Archive asset query advanced to `update-10403-8`.
- Application cache advanced to `v168`.
