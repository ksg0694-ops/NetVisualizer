# 포트폴리오 현재가 자동 동기화 보고

## 결과

- 2026-07-28 기준 보유 23개 행의 22개 고유 ticker를 모두 식별했다.
- 미국 8개 ticker와 한국 14개 ticker의 현재가, 통화, 가격일을 서버 캐시에 저장했다.
- 한국 ticker는 Yahoo Finance의 `.KS` 심볼로 변환하고 미국 ticker는 원래 심볼을 사용한다.
- 앱을 열 때 마지막 자동 갱신이 4시간보다 오래된 경우 백그라운드로 갱신한다.
- 서버는 최근 6시간 캐시를 사용해 반복 호출을 줄인다.

## 정합성 규칙

- 현재가는 0보다 커야 한다.
- 반환 통화는 보유행 통화와 같아야 한다.
- 한국 종목은 KRW, 미국 종목은 USD로 확인한다.
- 응답 실패나 통화 불일치 시 기존 캐시, 사용자 override, 입력 원화금액을 유지한다.
- 8월 투자자산 스냅샷은 18개 시세 보유행과 5개 원화 입력 fallback 행으로 다시 계산했다.

## 8월 투자자산 기준점

- 현재가 평가액: 42,427,676원
- 기존 입력 원화금액: 42,402,727원
- 차이: +24,949원
- 시세 평가 범위: 18/23행
- 외화 환율 범위: 100%

## 평균매입단가

- Google Sheet 입력 양식은 투자·연금 보유 23개 행을 포함한다.
- 사용자는 평균매입단가, 평단 통화, 사용자 메모만 입력한다.
- 매입원가, 미실현손익, 수익률은 입력 즉시 계산한다.
