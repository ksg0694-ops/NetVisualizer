# BankSalad Gmail Auto Sync 완료 보고서

## 결과

사용자는 뱅크샐러드에서 이메일로 파일을 보내기만 하면 된다. GitHub Actions가 15분마다 Gmail을 확인하고, 암호화 ZIP을 메모리에서 해제한 뒤 가계부 내역을 Supabase에 반영한다.

## 처리 흐름

1. Gmail 읽기 전용 권한으로 뱅크샐러드 발신 메일과 ZIP 첨부파일만 조회한다.
2. ZIP과 XLSX는 디스크에 저장하지 않고 메모리에서 처리한다.
3. 가계부 시트를 자동 선택하고 날짜·시간·구분·분류·금액·결제수단을 표준화한다.
4. 파일 내부 중복과 기존 DB 중복을 각각 제거한다.
5. 신규 거래만 저장하고 메일별 처리 건수만 감사 로그로 남긴다.

## 실제 반영 결과

- 원본 행: 1,670건
- 파일 내부 정확 중복: 34건
- 유효 거래: 1,636건
- 기존 DB와 중복: 297건
- 신규 저장: 1,339건
- 동일 메일 재실행 신규 저장: 0건

## 검증

- NetVisualizer 자동검사 13개 통과
- Python ZIP·파서 테스트 5개 통과
- Supabase 마이그레이션 적용 성공
- Gmail 건식 실행 성공
- Gmail 실제 실행 및 재실행 멱등성 검증 성공
- GitHub Pages 배포 성공 및 공개 페이지 HTTP 200 확인

## 보안

- Gmail 권한은 읽기 전용이다.
- ZIP 비밀번호, OAuth 비밀값, Supabase 서버 키는 GitHub Secrets에만 저장한다.
- 메일 본문, ZIP, 복호화 XLSX는 영구 저장하지 않는다.
- 개인 재무 테이블은 로그인한 소유자만 접근하도록 RLS를 적용한다.
