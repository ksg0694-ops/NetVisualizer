# Update 1.04.03 Todo Unified Editor — Report

## Outcome

Todo detail notes now use one continuous editing host, matching the stable editor architecture already used by Learning Archive.

## User impact

- Text selection can cross line boundaries.
- Up, down, left, and right caret movement continues across lines.
- Home, End, Enter, Backspace, Delete, and Tab have deterministic line behavior.
- Existing notes and autosave remain compatible.
