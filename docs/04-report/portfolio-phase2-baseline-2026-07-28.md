# Portfolio Phase 2 기준점

## 결과

- 투자자산 23개 항목을 Port별로 관리하는 화면과 계산 모델을 연결했다.
- 2026-08 시작 기준점은 42,402,727원이다.
- 기존 6월·7월 자산 이력은 변경하지 않았다.
- 현재 18개 ticker 모두 시세가 비어 있어 8월 기준점은 입력 원화금액을 사용한다.

## 평가 규칙

1. 수량·현재가·환율이 모두 있으면 `수량 × 현재가 × 환율`로 원화 평가한다.
2. 하나라도 없으면 기존 입력 원화금액을 유지한다.
3. 평균매입단가와 현재가의 통화가 같을 때만 원화 원가와 미실현 손익을 계산한다.
4. Port 합계와 Monthly Report는 동일한 평가 결과를 사용한다.
5. 월별 기준점은 종목 수량·가격·통화·가격일·환율·환율일·원화 평가액·Port를 함께 보관한다.

## 환율 기준

- 기준일: 2026-07-27
- EUR/KRW: 1,674.31원
- EUR/USD: 1.1389
- EUR/JPY: 186.37
- USD/KRW: 1,470.1115원 (`1,674.31 ÷ 1.1389`)
- JPY/KRW: 8.9839원 (`1,674.31 ÷ 186.37`)
- 출처: [ECB euro foreign exchange reference rates](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)

ECB 기준환율은 평가 참고값이며 실제 환전 체결가와 다를 수 있다.
