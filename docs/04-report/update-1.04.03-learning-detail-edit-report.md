# Update 1.04.03 Learning Detail Edit Report

## Result

The Learning Archive detail body is directly editable again. Users can click either a rendered line or the blank editor area to place the caret, then edit in the same WYSIWYG surface. `본문 저장` provides explicit confirmation in addition to autosave.

The former `노트 수정` control was relabelled to `분류 수정` because it edits field, item, Chapter, tags, and links rather than the note detail body.
