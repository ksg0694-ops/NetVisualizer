# Personal CFO Salary Flow v1 Report

Date: 2026-07-17
Phase: Report
Result: completed

## Delivered

- 최근 종료 급여기간의 실제 월급을 별도로 추출한다.
- 청년도약계좌의 출발·도착 계좌 중복을 제거해 월 70만원만 계산한다.
- 월급일 부근의 짝 없는 10만원 이체를 삼성증권 연금저축펀드로 계산한다.
- 신용대출 이자와 전세대출 현금흐름을 분리한다.
- 전세대출은 현금흐름 그래프에서 부채로 표현하되 부채·순자산 계산에는 연결하지 않는다.
- 월급통장과 생활비통장 잔액 목표를 합쳐 생활비 100만원 단일 노드로 표시한다.
- 위 배분 후 남은 월급을 원화 발행어음으로 계산한다.
- Personal CFO의 기본 네트워크 보기를 월급 배분 현금흐름으로 변경했다.
